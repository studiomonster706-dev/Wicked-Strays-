# WICKED STRAYS v1.1

Bilingual GitHub Pages starter site using the supplied WICKED STRAYS logo.

## Structure
- English: root 6 pages
- Japanese: `jp/` 6 pages
- Shared CSS: `css/style.css`
- Shared JS: `js/script.js`
- Logo: `images/logo.png`

## Publish with GitHub Pages
1. Create a public GitHub repository.
2. Upload the contents of this folder (not the ZIP itself).
3. Keep `index.html` at the repository root.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Choose `main` and `/ (root)`, then save.
7. Open the GitHub Pages URL after deployment.

## Before launch
- Replace `YOUR-EMAIL@example.com` with the real studio contact email.
- Add actual project artwork and project pages.
- Add YouTube/social links when ready.
- Consider adding a favicon using the logo.
